# 可选身体档案：几何、素材与热区作者说明

启用身体档案组件时先读[安装与边界](README.md)。素材、外观、私有字段和文风按作品配置；使用素材前核对再分发授权。

## 1. 人形：表层全息 / 里层真实

本组件使用整身图、逐行轮廓数据和部位热区。更换绘制方式时，同步调整下列数据与渲染器：

```
figdata.js   ar（宽高比） / img（图） / crop[宽%,高%,left%,top%]
             rows（每 2% 高度一行的躯体横向区间，从原图 alpha 描出）
             regions（每个部位的 cx/cy/rx/ry，已经和这张图对齐好）
```

- **整身图**按 `crop` 百分比铺满 `--ar` 比例的框；换图只改 `img` 与 `crop`，CSS 不用动。
- **兜底剪影**用 `rows` 画：每行一条圆头粗线，相邻行重叠成实心。图挂了（离线/被墙/CDN 失效）自动切过去，轮廓和真图几乎重合——不会出现「图没加载就变成另一个人的身材」。
- **部位热区**用 `regions`，形状由 `SHAPE` 剖面曲线决定（Catmull-Rom，两端必须收 0），宽度整块夹一次（取包含该点的行区间半宽），不要逐行求交——逐行会让曲线出折角。

### 两层的合成参数

| | 表层（全息） | 里层（真实） |
|---|---|---|
| 图 | `女性/男性-全息风` | `女性/男性-真实风` |
| 合成 | `mix-blend-mode:screen` + `contrast(1.62)` | 正常合成 + `drop-shadow` |
| 热区 | 不显示 | 淡白描边，hover 提亮 |
| 装饰 | 扫描带（上下渐变 + **左右羽化遮罩**） | 无 |

**两个必须核对的陷阱**：

1. **全息图自带一层略亮的背景板**，直接放进深色面板会露出一块矩形。解法是 `contrast` 把暗端压到 0、再 `screen` 让归零处等于面板底色。全息本来就该是「暗部透明、亮线发光」，压暗端不掉细节。
2. **扫描带左右是硬切边**。上下靠渐变收边不够，左右必须加 `mask-image: linear-gradient(90deg, transparent, #000 18%, #000 82%, transparent)`，否则永远是一块会动的矩形。动画被暂停（截图、省电模式）时也一样。

### 部位特写图

`IMGDATA` 里有每个部位的特写图，按状态分档（`干净 / 沾染精液 / 被外射 / 被内射 / 被同时内外射`）。热区气泡和部位卡按作品需要选择图像或文字；没配图的部位只显示文字，不留空框。

## 2. 插入点：换图与生图

四张整身图和全部部位特写图都写在 `assets/kits/body-dossier/figdata.js` 里，**换图只改这一处**，`figure.js` 与 CSS 都不用碰。

现成的套图不满意时，同一个文件底部有 `window.__REX_FIG__.prompt` —— **一条提示词对应一张图**，中文单句，不需要负向提示词，直接拿去生图、替换 URL 即可。

提示词的风格锚点只有两句，想换整套风格就全局替换这两句：

- 全息 = 青绿色线框 + 横向扫描纹理 + 深色背景 + 医学扫描质感
- 真实 = 写实皮肤/黏膜质感 + 柔和顶光 + 深色背景 + 解剖图谱构图

组件默认的素材配置（重设时同步解析器）：

- **口腔 / 乳房 只有两档**（干净、沾染精液）。后三档对这两处没有意义，多出来的档位只会让模型瞎写。
- **男性性器不出图**。没有配图就只给文字，不留空框——空框比没有更伤。

## 安装后的数据与行为核对

- 复制figdata.js、figure.js、dossier.js到项目src，在modules.json中按此顺序接在ui/sections定义之后、boot之前；确认sections的人物详情实际调用dossierHTML。
- NPC静态priv结构参考同目录content.example.json，按需选取字段，不整体覆盖用户content。
- 动态私有字段需声明status.npcPrivateFields并通过status.js白名单；默认并不接受任意npcs/me/sys对象。rel/fav等字段类型以实际解析器为准，不能用参考文案覆盖源码契约。
- 图像替换后同步ar/crop/rows/regions；不能只换URL不校热区。
- 实测整图失败、特写缺失、非法档位、不同体型、窄屏、减少动态、气泡关闭和模块卸载。尚未对当前作品执行的写NOT RUN。

## 参考字段的分工

组件NPC包含sex、surface、hooks、thought与priv；sex选择图形布局。surface是可见资料，hooks是印象，thought是可选的一句内心。priv按部位key映射到热区；fixed表示长期稳定细节，rt表示当下状态，st是支持的选图档位，ml按0–20映射条宽，spec用于额外键值表。各部位档位查figure.js的STLEVELS，不支持的词不应承诺有图。

换身体模型时同时改数据key、热区region、素材索引与解析白名单；只换显示标签不能完成迁移。字段与素材按作品需要配置。
