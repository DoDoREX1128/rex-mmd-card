# 可选人物身体档案组件

仅在用户题材与功能需求包含身体分层档案时使用。复制所需 JS 到项目源码，在 modules.json 中加入 figdata、figure、dossier，顺序放在 sections 之后；按作品配置 status.npcPrivateFields。content.example.json 是旧参考结构，不作为通用默认。

图像、配色、热区与私有字段由作品决定，不强制使用参考素材。不把该组件的字段、人设、视觉或测试套到所有卡。

详细几何、热区、素材替换与失败回退方法见[作者说明](authoring.md)。features.bodyDossier不是自动安装器，仍须复制模块并接入modules.json。
