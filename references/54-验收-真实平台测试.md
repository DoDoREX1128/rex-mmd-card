# 54 · 真实目标站与实体设备测试

本篇恢复可重复的步骤、用例、只读测量和证据模板。使用当前可用的浏览器工具，先读取其说明；不依赖某个固定bsk安装，也不凭空发明工具命令。


本地file或localhost仿平台仍是E3；真实MMD部署为E4，手机视口模拟也不是E5。缺目标环境时完成本地可做部分，E4/E5写NOT RUN。

## 2. 可见操作流程

1. 观察页面，确认打开的是本版，留首屏截图。
2. 逐一点击导航、主要入口和返回，观察可见变化，每次重新获取当前元素，避免复用过期定位。
3. 长列表实际滚动到底，检查底部可达；测宽屏与窄屏、短高、横屏及键盘。
4. 按实际支持功能测试状态、创建、存档、草稿与发送。操作前截图→操作→等待可观察结果→操作后截图。
5. 查看控制台异常，记录警告原因；无异常不等于功能已生效。
6. 二次进入与刷新，再查进度和实例；保存验证要重载/重开回读，不只看“已保存”toast。
7. 记录结果与未执行项，关闭仅为本次测试创建的资源；用户已有页面按要求保留。

黑盒通过依据是用户能看见的效果。开发时可读源码或做单元探针定位，但用内部方法直接改状态、改localStorage或mock返回值，不能算目标站链路通过。

## 3. 只读布局测量（工具允许时）

以下是可嵌入浏览器只读evaluate的JS表达式，不是指定某个CLI：

```js
// 横向溢出；读数需要和截图、实际滚动一起判断
({width:innerWidth,scrollWidth:document.documentElement.scrollWidth,
  overflow:document.documentElement.scrollWidth>innerWidth+1})

// 一个已定位可见按钮的中心是否被其他节点遮住
// el由浏览器工具当前观察取得，不用猜选择器
function hitTest(el) {
  const r=el.getBoundingClientRect();
  const x=Math.max(0,Math.min(innerWidth-1,r.left+r.width/2));
  const y=Math.max(0,Math.min(innerHeight-1,r.top+r.height/2));
  const top=document.elementFromPoint(x,y);
  return {width:r.width,height:r.height,clear:top===el||el.contains(top)};
}

// 字体加载状态不等于指定字族真的被使用，需对目标节点读computedStyle
({status:document.fonts.status,count:document.fonts.size})
```

测iframe时确认正在测哪个document；不能拿外层scrollWidth代替内层抽屉。Canvas/WebGL还需肉眼核对画面、触摸、丢失上下文与资源释放。

## 5. 状态、创建与存档专项

| 专项 | 操作与预期 |
|---|---|
| 两轮状态 | 实际模型输出与UI一致，缺字段不清零，原始数据块不露出 |
| 坏输出 | 在本地注入坏JSON；目标站自然出现时记录，保留旧值，不用改内部变量假通过 |
| 创建 | 必填与可选、返回、默认值、草稿可改、失败不退出；选项不会自动变成已发生剧情 |
| 命名槽 | 保存两份不同值→读各自槽→核对至少两个值、空列表及其他槽 |
| 真保存 | 刷新/重开后恢复；拒写时可见；重试后再刷新确认 |
| 续档 | 读取只恢复快照不发消息，下一次确认带一次上下文，失败仍可重试 |
| 会话与重入 | A/B会话不串数据，退出回来不叠实例；切宽窄不丢关键草稿 |
| 主题/外链 | 深浅切换、真实宿主表面、图片/字体失败、减少动态 |

“已点击”“handler返回ok”“没有报错”均不足以PASS。发送至少区分点击已触发、消息出现、回复完成、服务端回读；超时显示结果未确认，不自动重发。

## 7. 故障与收尾

| 现象 | 排查 |
|---|---|
| 工具没有浏览器能力 | 完成本地验证，目标站NOT RUN，保留可执行用例 |
| 元素定位过期 | 重新观察；不要重放旧引用盲点 |
| 截图空白/交互不到 | 核对iframe、Canvas与活动标签页，先定位真实可见表面 |
| 窄屏仍溢出 | 查内层scrollWidth、flex min-height、固定高度和软键盘 |
| 原生面板被Frame盖住 | 检查Host让位、返回按钮、当前capabilities |
| 保存toast成功但刷新丢失 | 查真实scope、SDK响应、后续旧写覆盖、读档失败；不直接新开覆盖原档 |
