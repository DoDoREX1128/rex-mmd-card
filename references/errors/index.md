# 错题本索引（生成文件）

> 本文件由 `scripts/gen-errors.mjs` 从 `errors.json` 生成，**不要手改**。
> 记新条目用 `node scripts/error-log.mjs --add`；判决与分层规则见 [README](README.md)。
> 更新：2026-10-28 · 条目 **30** · 有效 **30** · 失效 **0**

## 怎么用

1. **先定版本**：新版（`chatVersion:1`）只看 `v1` 与 `both`；旧版（`0`）只看 `v0` 与 `both`。跨版本套结论是本库最常见误用。
2. **再定分层**：按「故障发生在哪一层」找（点火 / 字符集 / 正则 / 能力 / 协议 / 样式 / 数据 / 可观测 / 验收 / 工具 / 流程），不按症状找。症状会重叠，层不会。
3. **看判决**：只有 `已复现` 能直接当排障依据。`待复现` 是线索；`失效区`里的条目**不要再按它排查**。
4. **命中就回写**：按某条解决了，把 `date` 更新为当天；没解决或发现归因错了，改判决而不是新开一条。
