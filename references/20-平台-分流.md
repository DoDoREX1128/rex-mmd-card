# 20 · 两种环境，三种交付路线

新版 chatVersion=1，旧版0/缺省是平台环境；同层/原生是界面形态。旧版原生可叠轻量 Host；不得跨环境套 SDK、稳定钩子或导入格式。

| 路线 | 构建 | 校验 |
|---|---|---|
| 新版沙盒 | build --route sandbox | --platform sandbox |
| 旧版原生 | build --route native | --platform legacy |
| 旧版同层 | pack-samelayer --host --frame | --platform legacy |

init --route sandbox/native/same 复制各自起点，--out 指定项目路径。默认保留已有文件；--with-persona 才复制示例人设。

新版独立正则包：chatVersion/pageDepth/statusbar/beginning/regex_scripts 必填，personality 可选但导入正则不读；旧版包恰好 pageDepth/statusbar/beginning/regex_scripts 四键，不带 chatVersion 或 personality。旧版规则 id 固定 -1，新版为负整数。两者 statusbar 均可空。

旧版原生卡：纯文字、换肤、KV/气泡、逐消息引擎按需。旧版同层：Host 适配 DOM，Frame 负责界面，不代表拥有所有原生动作。新版全屏用 sdk.stage，并非旧版 iframe 同层。

整卡与独立正则包是不同格式。新版导入要新建卡、首次保存前选择新版；导入到已有卡不能切版本。想换环境需新卡及相应迁移，不只改 JSON 中的数字。
