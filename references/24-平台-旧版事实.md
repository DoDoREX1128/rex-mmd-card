# 24 · 旧版原生与逐消息引擎

旧版独立正则包恰好四键 pageDepth/statusbar/beginning/regex_scripts，每条规则 id=-1。不带 SDK、新版 chatVersion 或 personality 字段；人设另贴，世界书另导。空状态栏可用。

逐消息状态引擎用 onerror 等已验载体定位容器；文档级 script 可用于主题或同层单例初始化，不能因为逐消息 currentScript 不可依赖就禁止所有 script。

HTML 属性与内部 JS 引号分别转义。外层单引号时内部可用双引号，外层双引号时内部可用单引号；同类裸引号会提前结束属性。JSON.stringify 是否可用取决于编码去向，不作全局禁令。不要把外内都写成单引号。

onerror 需要 closest 容器时放容器闭合之前，执行后清理点火器。现代语法能力按目标验证，不机械降到 ES5。复杂 onclick 改动态绑定，宿主事件冒泡按原生控件需要处理。

旧版 white-space:pre-line 会放大标签换行；自有容器设置 white-space:normal。跨模块 ID 用实例前缀或时间戳避冲突；独立 Frame 内可局部 ID。

纯文字/零JS KV/逐消息状态栏/主题运行时分别选型。assets/native 是轻量 KV 示例，使用 [status]hp::数值;;loc::地点[/status]；若换 JSON，必须配自己的解析与转义，不拿新版 SDK 解析器原样移植。

类名、层级与 DOM 是目标观察，不是永久 API。旧版没有官方 sdk.save；本地偏好与剧情存档分开，存档要作品/账号/角色/会话作用域。新版相关限额和选择器不能直接套旧版。
