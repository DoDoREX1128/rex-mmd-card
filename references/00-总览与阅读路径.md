## 3. 五条阅读路径

### ① 第一次做卡

```
00 → 01 心流（开场四问）→ 10 方案 → 20 分流 → 43 封面与捏人 → 42 视觉 → 40 卡架构 → 52 静态验收
```

不要一上来读 22：同层卡是三条路线里维护成本最高的。

### ② 复刻一张成品卡

```
00 → 50 示例拆解 → 51 复刻验收 → 45 骨架与皮肉 → 43 封面与捏人 → 54 真浏览器
```

先复现工程骨架，再换创作皮肉；顺序反了就是把别人的皮肉一起抄了。

### ③ 已有项目改造

```
00 → 01 心流的 4.2 → 10 三问与方案 §6 体检清单 → 53 真平台踩坑 → 对应平台的架构文档
```

先修管道，最后才重做工程骨架。

### ④ 只做视觉，不碰逻辑

```
00 → 42 视觉 → 41 基线 → 43 封面与捏人 → 45 骨架与皮肉（只改 tokens）
```

### ⑤ 卡不渲染 / 按钮全哑

```
00 → 53 真平台踩坑（点火拓扑 / 字符集 / 载体）→ 54 真浏览器取证
```
