# 00 · 总览与阅读路径

本技能只处理MMD，不处理酒馆。资料按任务读取，不要求从00顺序读到55。编号用于检索，不代表每张卡必须实现全部模块。

## 1. 环境、呈现与证据

- 新版沙盒：公开SDK、槽位、舞台；21/25/40。
- 旧版原生：保留旧页聊天，文字/KV/气泡/换肤/逐消息引擎；24与assets/native。
- 旧版同层：Host适配旧页，隔离Frame承载UI；22与assets/samelayer。
- 状态与内容、视觉与工程都可独立交付；纯人设不强制工程化。
- S0–S5是制作阶段，E1生成/E2静态/E3本地行为/E4目标站/E5实体设备是证据，不能相互替代。

## 2. 常见任务的最短有效路径

| 任务 | 建议阅读与执行 |
|---|---|
| 纯人设/开场 | 32；需要世界资料时31；不造空状态栏 |
| 一句话新卡 | 11→10；需要代码再20→对应路线；从零整卡先02建工作区，复杂界面才原型 |
| 用户审阅、修改内容、同步导入文件 | 02：交付区/工程区、三份审阅稿、冲突保护与重建 |
| 新版状态HUD | 20→21/25→30→40→52；持久化再33 |
| 旧版原生状态/换肤 | 20→24→assets/native→30/42（仅适用部分）→52 |
| 旧版独立网页UI | 20→22→assets/samelayer→40的通用模块方法（不套SDK）→52/54 |
| 已有卡不渲染 | 01资产体检→53→对应平台机制；先复现再改 |
| 复刻工艺 | 50→51→45；按约定补43/44；不把历史动作当自带能力 |
| 换肤/宿主弹窗 | 41/42→47；外链/字体再46；逐表面验 |
| 继续旧项目 | 01→现有记录→核对真实构建→已授权未完项 |
| 发布/交付 | 52→55；有目标与设备再54，未运行明示 |

封面、捏人、身体档案、地图与多槽均按需求选。身体档案的几何、热区和素材替换见[可选作者说明](../assets/kits/body-dossier/authoring.md)。
