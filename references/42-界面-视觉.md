# 42 · 视觉设计

「完美」在卡里的定义很具体：**进第一屏 3 秒内，玩家能感觉到这是为他这个题材做的**，而不是把默认模板换了颜色。所以视觉靠三件事，不靠堆特效：配色关系的准确性、字体与留白的克制、动效的节奏。

---

## 1. 一句话 → 视觉参数

先定基调，再从基调推出 token。不要反过来（先挑好看的颜色再强行嵌入题材）。

| 题材 | 主色 | 辅色 | 底 | 字体 | 质感 |
|---|---|---|---|---|---|
| 修仙 / 古风 | `#c9a962` 哑金 | `#7a1f1f` 暗朱 | `#0d0b0a` 墨 | 衬线 | 宣纸 |
| 西幻 / 黑暗 | `#8b7355` 旧铜 | `#4a1f3d` 紫血 | `#12100e` | 衬线 | 羊皮 |
| 赛博 / 科幻 | `#6fe3c4` 高彩青 | `#ff2e63` 品红 | `#07090d` | 无衬线 | 霓虹 |
| 民国 | `#a67c52` 桐油 | `#2d4a3e` 深墨绿 | `#1a1613` | 衬线 | 胶片 |
| 校园 / 日常 | `#7fb2c9` 雾蓝 | `#e8a798` 浅陶 | `#f7f5f2` 米白 | 无衬线 | 干净 |
| 末世 / 生存 | `#b8621b` 锈 | `#3d4a3a` 苔 | `#0f0e0c` | 无衬线 | 颗粒 |

> 这套 token 与 `assets/skeleton/base.css` 实现一致，也与 [41 界面基线](41-界面-基线.md) §5.2 的三级描边同源。字号、行高、密度见 41 §7；本文不再重复一套。

**主色只用一个。** 第二个亮色会立刻让界面变廉价。辅色只用于"危险/亲密/选中"这类语义点。

## 2. CSS 变量（唯一改颜色的地方）

作用域写 `[data-chat="root"]`，不写 `:root`：平台把全局选择器（`*` / `html` / `body` / `:root`）列为文案禁令，而 root 是聊天页的稳定节点，变量照样向下继承。

```css
[data-chat="root"] {
  --rex-bg:       #0d0b0a;
  --rex-surface:  #171310;
  --rex-surface2: #1f1a15;
  --rex-text:     #e8dfd4;
  --rex-muted:    #b3a693;
  --rex-dim:      #8c8071;
  --rex-accent:   #c9a962;
  --rex-accent2:  #7a1f1f;
  /* 三级描边：主色 + 透明度。灰线是框，主色线是饰 */
  --rex-line:     color-mix(in srgb, var(--rex-accent) 20%, transparent);
  --rex-line2:    color-mix(in srgb, var(--rex-accent) 32%, transparent);
  --rex-line3:    color-mix(in srgb, var(--rex-accent) 52%, transparent);
  --rex-radius:   10px;
  --rex-shadow:   0 2px 12px rgba(0,0,0,.45);
}
```

同时把平台的 29 个 `--chat-*` 映射到这套（完整清单见 [23-平台-事实表](23-平台-事实表.md) §5）。映射范围决定换肤是否彻底：

```css
[data-chat="root"][data-theme="dark"] {
  /* 气泡与整页（10 个，含 3 个别名） */
  --chat-bg: var(--rex-bg);
  --chat-surface: var(--rex-surface);
  --chat-text: var(--rex-text);
  --chat-text-muted: var(--rex-muted);
  --chat-border: var(--rex-line);
  --chat-accent: var(--rex-accent);
  --chat-share-pick-bg: var(--rex-surface2);
  --chat-bubble-user-bg: var(--rex-bg);
  --chat-bubble-ai-bg: var(--rex-bg);
  --chat-bubble-text: var(--rex-text);

  /* 底栏与输入（8 个） */
  --chat-composer-bg: var(--rex-surface);
  --chat-composer-text: var(--rex-text);
  --chat-shortcut-bg: var(--rex-surface2);
  --chat-shortcut-text: var(--rex-muted);
  --chat-input-bg: var(--rex-surface);
  --chat-input-text: var(--rex-text);
  --chat-input-placeholder: var(--rex-dim);
  --chat-input-border: var(--rex-line);

  /* 白名单弹窗（10 个） */
  --chat-modal-bg: var(--rex-surface);
  --chat-modal-surface: var(--rex-surface2);
  --chat-modal-text: var(--rex-text);
  --chat-modal-muted: var(--rex-muted);
  --chat-modal-accent: var(--rex-accent);
  --chat-modal-input-bg: var(--rex-bg);
  --chat-modal-input-text: var(--rex-text);
  --chat-modal-cancel-bg: var(--rex-surface2);
  --chat-modal-btn-bg: var(--rex-surface2);
  --chat-modal-btn-border: var(--rex-line);

  /* 别名（1 个） */
  --chat-more-item-bg: var(--rex-surface2);
}
```

三条判据：

1. **只映射 `bg` / `text` / `accent` 不够。** 底栏、输入框、白名单弹窗走另外 18 个独立变量，改那三个带不动。
2. **写 `[data-chat="root"][data-theme="dark|light"]`**（特异性 0,2,0）才能跟随深浅色；只写 root（0,1,0）也可覆盖，但浅色主题下会错。
3. **别名保持 `var()`**。`--chat-bubble-*` 与 `--chat-more-item-bg` 是引用型取值，写死色值即切断传导链。

映射完在预览里核对：气泡、顶栏、底栏、发送键、`+` 面板、模型设置弹窗、对话设置弹窗是否同步变色；未接入的面板单列为限制，不要宣称已覆盖。

## 3. 字体

**只用系统字体栈，不引外链字体。** 理由：外链受白名单与跨域限制，加载失败时排版会崩；中文网络字体动辄 5–10MB，手机上等于重大风险。

```css
/* 变量名就是骨架里这三个，别改名——改错不报错，只会静默回落到 serif */
--rex-serif: "Noto Serif SC", "Source Han Serif SC", "Songti SC", "SimSun", serif;
--rex-sans:  "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
--rex-num:   "DIN Alternate", ui-monospace, monospace;
```

- 标题用衬线 + `letter-spacing: .02em`，古风题材可到 `.08em`。
- 间距只用两档：`--rex-pad`（页面边距，手机 16 / 平板 20 / 桌面 24）与 `--rex-gap`（块间距，12 / 14）。**不要在组件里写魔法数字**，否则换断点时会有一半元素不对齐。
- 数字（血量、金币）用等宽，避免跳动。
- 正文 `font-size: 15px / line-height: 1.75`（手机），PC 提到 `16px / 1.8`。

## 4. 层级与留白

```
z-index 0      背景层（图 / 渐变 / 噪点）
z-index 10     内容层
z-index 100    面板层
z-index 900    舞台内浮层
z-index 1–999  气泡内装饰（默认落点）
z-index 3500–7999  页面级浮层（新版安全带）
```

为什么不是 1000–1999：舞台节点自带 `z-index`（`content` 2000 / `full` 3000），1000–3499 是空档，落在这里的浮层会被舞台压住；8000 起是平台临时浮层（分享 loading、输入区提示、长按菜单、alert、snackbar），越过就会盖住它们。平台 header / composer / messages 实测是 `z-index:auto` + `position:static`，不在 8000 段。`【实机】`

**气泡里的浮层翻不出气泡**：`[data-chat="message-body"]` 的 `opacity:.9` 创建层叠上下文，写多大都只在该气泡内比较。需要跨气泡的浮层挂 `[data-slot="left" | "right"]`。

旧版层级另有一套（弹窗 10075、两侧容器 9999、长按菜单 99999），见 [24](24-平台-旧版事实.md) §5。

**留白规则**：面板内边距 `16px`（手机）/ `24px`（PC）；块间距 `12px`；不要在 720px 宽的屏幕上塞三列。

## 5. 动效

三条，不多不少：

| 场景 | 时长 | 缓动 |
|---|---|---|
| 进场（fade + 位移 8–12px） | 240–400ms | `cubic-bezier(.2,.8,.2,1)` |
| 状态变化（数字滚动、条宽） | 300ms | `ease-out` |
| 场景切换（淡出 → 淡入） | 200 + 240ms | `ease-in-out` |

**硬要求**

- 所有动效包在 `@media (prefers-reduced-motion: no-preference)` 里。系统开了"减少动态"就全关。
- 不做无限循环的呼吸/闪烁（沉浸氛围可加，但必须能被设置关掉）。
- 不用 `transform: scale` 做按钮反馈（会糊），用 `translateY(1px)` + 背景变化。

## 6. 质感（三选一，不要叠加）

**宣纸**：`repeating-linear-gradient` 极细横纹 + 低透明度噪点。

```css
background-image:
  repeating-linear-gradient(0deg, rgba(255,255,255,.012) 0 1px, transparent 1px 3px),
  radial-gradient(circle at 30% 20%, rgba(255,255,255,.03), transparent 60%);
```

**霓虹**：只在边框与文字上做 `box-shadow` 的短半径发光，底色保持纯黑。大面积发光是廉价感的来源。

**颗粒**：一张 64×64 的 SVG `feTurbulence` 转 base64 做 `background-blend-mode: overlay`，透明度 ≤6%。

## 7. 图标

**内联 SVG，不用远程 PNG。** 卡 B 用了 21 张远程图，链接一挂整套 UI 就成白框。

统一规格：`24×24` viewBox，`stroke: currentColor`，`stroke-width: 1.5`，`fill: none`，圆角端点。同一套里不要混实心和线性。

（唯一的远程图例外是人物档案的整身图与部位特写图，见第 9 节——它们有兜底，挂了不会塌成白框。）

## 8. 人形：表层全息 / 里层真实

人物档案的核心是那张人形。**不要用几何路径手画**——手画的骨架永远像「拼接的长方体」，怎么调都不像人。正确做法是**用整身图 + 逐行轮廓数据**：

```
figdata.js   ar（宽高比） / img（图） / crop[宽%,高%,left%,top%]
             rows（每 2% 高度一行的躯体横向区间，从原图 alpha 描出）
             regions（每个部位的 cx/cy/rx/ry，已经和这张图对齐好）
```

- **整身图**按 `crop` 百分比铺满 `--ar` 比例的框；换图只改 `img` 与 `crop`，CSS 不用动。
- **兜底剪影**用 `rows` 画：每行一条圆头粗线，相邻行重叠成实心。图挂了（离线/被墙/CDN 失效）自动切过去，轮廓和真图几乎重合——不会出现「图没加载就变成另一个人的身材」。
- **部位热区**用 `regions`，形状由 `SHAPE` 剖面曲线决定（Catmull-Rom，两端必须收 0），宽度整块夹一次（取包含该点的行区间半宽），不要逐行求交——逐行会让曲线出折角。

### 两层的合成参数

| | 表层（全息） | 里层（真实） |
|---|---|---|
| 图 | `女性/男性-全息风` | `女性/男性-真实风` |
| 合成 | `mix-blend-mode:screen` + `contrast(1.62)` | 正常合成 + `drop-shadow` |
| 热区 | 不显示 | 淡白描边，hover 提亮 |
| 装饰 | 扫描带（上下渐变 + **左右羽化遮罩**） | 无 |

**两个必须核对的陷阱**：

1. **全息图自带一层略亮的背景板**，直接放进深色面板会露出一块矩形。解法是 `contrast` 把暗端压到 0、再 `screen` 让归零处等于面板底色。全息本来就该是「暗部透明、亮线发光」，压暗端不掉细节。
2. **扫描带左右是硬切边**。上下靠渐变收边不够，左右必须加 `mask-image: linear-gradient(90deg, transparent, #000 18%, #000 82%, transparent)`，否则永远是一块会动的矩形。动画被暂停（截图、省电模式）时也一样。

### 部位特写图

`IMGDATA` 里有每个部位的特写图，按状态分档（`干净 / 沾染精液 / 被外射 / 被内射 / 被同时内外射`）。热区点开的气泡和下方部位卡都用它，**不要只写文字**——一张图胜过三行形容词。没配图的部位（男根/阴囊）就只显示文字，不要留空框。

## 9. 插入点：换图与生图

四张整身图和全部部位特写图都写在 `assets/skeleton/figdata.js` 里，**换图只改这一处**，`figure.js` 与 CSS 都不用碰。

现成的套图不满意时，同一个文件底部有 `window.__REX_FIG__.prompt` —— **一条提示词对应一张图**，中文单句，不需要负向提示词，直接拿去生图、替换 URL 即可。

提示词的风格锚点只有两句，想换整套风格就全局替换这两句：

- 全息 = 青绿色线框 + 横向扫描纹理 + 深色背景 + 医学扫描质感
- 真实 = 写实皮肤/黏膜质感 + 柔和顶光 + 深色背景 + 解剖图谱构图

两处刻意的取舍，别改回去：

- **口腔 / 乳房 只有两档**（干净、沾染精液）。后三档对这两处没有意义，多出来的档位只会让模型瞎写。
- **男性性器不出图**。没有配图就只给文字，不留空框——空框比没有更伤。
