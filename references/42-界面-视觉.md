# 42 · 视觉设计

「完美」在卡里的定义很具体：**进第一屏 3 秒内，玩家能感觉到这是为他这个题材做的**，而不是把默认模板换了颜色。所以视觉靠三件事，不靠堆特效：配色关系的准确性、字体与留白的克制、动效的节奏。

---

## 1. 一句话 → 视觉参数

先定基调，再从基调推出 token。不要反过来（先挑好看的颜色再强行嵌入题材）。

| 题材 | 主色 | 辅色 | 底 | 字体 | 质感 |

| 西幻 / 黑暗 | `#8b7355` 旧铜 | `#4a1f3d` 紫血 | `#12100e` | 衬线 | 羊皮 |
| 赛博 / 科幻 | `#6fe3c4` 高彩青 | `#ff2e63` 品红 | `#07090d` | 无衬线 | 霓虹 |
| 民国 | `#a67c52` 桐油 | `#2d4a3e` 深墨绿 | `#1a1613` | 衬线 | 胶片 |
| 校园 / 日常 | `#7fb2c9` 雾蓝 | `#e8a798` 浅陶 | `#f7f5f2` 米白 | 无衬线 | 干净 |

## 2. CSS 变量（唯一改颜色的地方）

作用域写 `[data-chat="root"]`，不写 `:root`：平台把全局选择器（`*` / `html` / `body` / `:root`）列为文案禁令，而 root 是聊天页的稳定节点，变量照样向下继承。

```css
[data-chat="root"] {
  --rex-bg:       #0d0b0a;
  --rex-surface:  #171310;
  --rex-surface2: #1f1a15;
  --rex-text:     #e8dfd4;
  --rex-muted:    #b3a693;
  --rex-dim:      #8c8071;
  --rex-accent:   #c9a962;
  --rex-accent2:  #7a1f1f;
  /* 三级描边：主色 + 透明度。灰线是框，主色线是饰 */
  --rex-line:     color-mix(in srgb, var(--rex-accent) 20%, transparent);
  --rex-line2:    color-mix(in srgb, var(--rex-accent) 32%, transparent);
  --rex-line3:    color-mix(in srgb, var(--rex-accent) 52%, transparent);
  --rex-radius:   10px;
  --rex-shadow:   0 2px 12px rgba(0,0,0,.45);
}
```

构建器compileTheme读取theme.dark与theme.light，合并默认色板，分别输出[data-chat="root"][data-theme="dark"]与light规则，映射29个已记录--chat-*（含引用别名），清单见23。覆盖bg/text/accent不等于覆盖全部输入与弹窗变量。

```json
{"theme":{"dark":{"bg":"#10161c","surface":"#1a242e","text":"#e8edf2","accent":"#8dd7c4"},"light":{"bg":"#f5f7f6","surface":"#ffffff","text":"#182b25","accent":"#155e4e"}}}
```

保留别名的var()引用，切主题检查正文、输入、占位符、按钮和选中态；作者组件需要引用对应token。颜色桥能否影响宿主另见47，不能从iframe内变色推定所有宿主面板同步。纯旧版原生或隔离Frame用自己的根与变量，不套data-chat。

## 3. 字体

系统字体栈是稳妥起点；需要外链字体时核对授权、体积、CSP/CORS和回退。原因：外链受白名单与跨域限制，加载失败时排版会崩；中文网络字体动辄 5–10MB，手机上等于重大风险。

```css
/* 变量名就是骨架里这三个，别改名——改错不报错，只会静默回落到 serif */
--rex-serif: "Noto Serif SC", "Source Han Serif SC", "Songti SC", "SimSun", serif;
--rex-sans:  "Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif;
--rex-num:   "DIN Alternate", ui-monospace, monospace;
```

- 标题用衬线 + `letter-spacing: .02em`，古风题材可到 `.08em`。
- 间距只用两档：`--rex-pad`（页面边距，手机 16 / 平板 20 / 桌面 24）与 `--rex-gap`（块间距，12 / 14）。**不要在组件里写魔法数字**，否则换断点时会有一半元素不对齐。
- 数字（血量、金币）用等宽，避免跳动。
- 正文 `font-size: 15px / line-height: 1.75`（手机），PC 提到 `16px / 1.8`。

## 4. 层级与留白

```
z-index 0      背景层（图 / 渐变 / 噪点）
z-index 10     内容层
z-index 100    面板层
z-index 900    舞台内浮层
z-index 1–999  气泡内装饰（默认落点）
z-index 3500–7999  页面级浮层（已记录部署参考，需实测）
```

为什么不是 1000–1999：舞台节点自带 `z-index`（`content` 2000 / `full` 3000），1000–3499 是空档，落在这里的浮层会被舞台压住；8000 起是平台临时浮层（分享 loading、输入区提示、长按菜单、alert、snackbar），越过就会盖住它们。平台 header / composer / messages 实测是 `z-index:auto` + `position:static`，不在 8000 段。`【实机】`

**气泡里的浮层翻不出气泡**：`[data-chat="message-body"]` 的 `opacity:.9` 创建层叠上下文，写多大都只在该气泡内比较。需要跨气泡的浮层优先舞台或存在的公开槽位；left/right在窄屏可能不存在。

旧版层级另有一套（弹窗 10075、两侧容器 9999、长按菜单 99999），见 [24](24-平台-旧版事实.md) §5。

**留白规则**：面板内边距 `16px`（手机）/ `24px`（PC）；块间距 `12px`；不要在 720px 宽的屏幕上塞三列。

## 5. 动效

常见时长参考：

| 场景 | 时长 | 缓动 |
|---|---|---|
| 进场（fade + 位移 8–12px） | 240–400ms | `cubic-bezier(.2,.8,.2,1)` |
| 状态变化（数字滚动、条宽） | 300ms | `ease-out` |
| 场景切换（淡出 → 淡入） | 200 + 240ms | `ease-in-out` |

**交互与性能检查**

- 所有动效包在 `@media (prefers-reduced-motion: no-preference)` 里。系统开了"减少动态"就全关。
- 不做无限循环的呼吸/闪烁（沉浸氛围可加，但必须能被设置关掉）。
- 按钮可用缩放、位移或背景反馈，按像素清晰度、触控和减少动态实测选择，不强制某一种。

## 6. 三种质感起点（可选、可组合）

**宣纸**：`repeating-linear-gradient` 极细横纹 + 低透明度噪点。

```css
background-image:
  repeating-linear-gradient(0deg, rgba(255,255,255,.012) 0 1px, transparent 1px 3px),
  radial-gradient(circle at 30% 20%, rgba(255,255,255,.03), transparent 60%);
```

**霓虹**：只在边框与文字上做 `box-shadow` 的短半径发光，底色保持纯黑。大面积发光是廉价感的来源。

**颗粒**：一张 64×64 的 SVG `feTurbulence` 转 base64 做 `background-blend-mode: overlay`，透明度 ≤6%。

## 7. 图标

小型功能图标优先内联SVG；远程位图也可以，但需要失败回退。 卡 B 用了 21 张远程图，链接一挂整套 UI 就成白框。

统一规格：`24×24` viewBox，`stroke: currentColor`，`stroke-width: 1.5`，`fill: none`，圆角端点。同一套里不要混实心和线性。

人物、地点、封面等远程素材都按46验失败、加载与回退，不把某类素材定为唯一例外。
