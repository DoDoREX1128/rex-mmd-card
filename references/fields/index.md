# 字段库索引（生成文件）

> 本文件由 `scripts/gen-fields.mjs` 从 `fields.json` 生成，**不要手改**。
> 增删字段用 `node scripts/field-add.mjs`；命名与分类规则见 [README](README.md)。
> 更新：2026-10-28 · 条目 **118** · 分类 13

## 怎么用

1. **先查重**：按语义搜本页，或 `node scripts/field-add.mjs --find 体力`。近义先看「冲突组」，同组只留一个。
2. **再定形**：选类型（bar / num / tag / text / enum / bool / list）、生命周期（每轮 / 阶段 / 一次性）、范围。
3. **按需登记**：项目字段写进 `content.status.fields` 并同步协议；加入本候选库时另按库内 2–4 字简短命名校验。项目可自定义更长或中文键，无需先入库。

库内字段名是**语义名**，显示名放 `label`；库内缩写习惯是 2–4 个小写字母，不是平台或项目运行时限制。候选 enum/bool/list 等类型也不代表默认状态解析器已支持，接入前映射或扩展。
