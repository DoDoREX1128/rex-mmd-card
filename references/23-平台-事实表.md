## 2.2 运行时行为（什么时候发生什么）

**功能栏静态**（v1）`source`：statusbar 字段只在装载时渲染一次：渲染函数 h_() 没有重渲染路径，且它的正则输入是 statusbar 字段自身，不是消息内容。

后果：AI 每轮输出新状态不会让功能栏变化。动态状态必须由作者 JS 改 DOM（message:done 里改已有节点的文字/class/内联 style）。

> 旧版不适用：旧版状态栏是逐消息渲染，每条消息各自点火，机制完全不同

**状态的三种载体**（同一数值只能有一个真值来源）：

| 载体 | 寿命 | 可用 |
|---|---|---|
| 平台状态变量 | 本轮进提示词；快照随 AI 消息保存；回溯与重生成按楼层恢复 | ✅ |
| sdk.save | 服务端持久化、跨设备；不会自动进上下文；不能改宿主聊天历史 | ✅ |
| sdk.cache | 会话内临时；刷新即失 | ✅ |

同一剧情数值只能有一个真值来源。平台状态变量与 sdk.save 不得各维护一份，否则回溯/读档/重生成后会出现两份真值。

平台状态变量：业务规则已确认存在（仅新页可开、最多 6 层 80 键、快照随消息按楼层回溯、{{var}} 只替换本轮新组装内容、分享页与瘦预览可读不可写），但官方 contract.json 未收录参数、返回值与导入字段。结论只有一句：契约未公布，不是不存在。可以讲行为边界，不能编造签名；写代码前先要用户的导出样本。

**实现细节**

| 项 | 事实 |
|---|---|

| save.get | 同步抛 SdkError，不是返回错误码；不 try/catch 会整段脚本失效 |

## 9. 正则与替换机制

slash 形态合法 flags：`gimsuy`，缺 `g` 自动补；字面量分支对元字符转义。

写成 `/…/` 但语法错：整条规则静默丢弃，不降级为字面量。

`__` 前缀：整条规则被丢弃，可用于临时停用。执行顺序：按 regexSort 升序执行。

输出预算：`max(262144, inputLength*4)`；超限时整条规则回滚，仅在调试面板告警。

替换记号：$1 / $名字 / {{random:甲::乙::丙}}。

## 10. 净化

白名单 62 项：p b a div span h1 h2 h3 h4 h5 h6 ul li ol strong em br img pre font i button table th tr td input textarea label select option video script user summary details code blockquote hr del thead tbody s svg g path circle ellipse rect line polyline polygon text tspan defs use linearGradient radialGradient stop clipPath title style。

会被删除：iframe / link / meta / base / form / object / embed；属性：data-*（作者自写） / aria-* / role。

非白名单标签按正则剥壳，只删标签保留文字；标签名字符类不含连字符，故 <status> 会存活、<状态> 被整段剥掉。2026-10-29 起内容协议改用方括号 [status]，不再依赖这条存活性；尖括号写法仅作旧卡兼容。

## 11. 静默失败清单

1. chatVersion 写成 0 或漏写：规则照装，sdk.* 与 [data-chat] 全不在，无报错
2. findRegex 写成 /…/ 但语法错：整条丢弃，无报错
3. 字面量匹配式重复：后一条永不命中
4. 可见 HTML 的标记没接进 statusbar/beginning/前序替换：界面永不出现
5. 能力名或事件名拼错：永不生效、永不触发
6. 自写 data-* 被净化：后续 querySelector 全查不到
7. z-index 落在 1000–3499：被舞台（2000/3000）压住
8. 替换产物超输出预算：整条规则回滚，仅调试面板可见
9. sdk.on 写进 message:mount 回调：每挂一条气泡多订一份
10. 在 message:mount 里读 message-body 当正文：读到「消息生成中」占位
11. 内容协议标记 [status] 没有规则消耗：模型每轮吐的 JSON 会原样显示在气泡里
12. 顶层直接读写 DOM：脚本在 Vue 挂载之前执行完，元素恒为 null，无报错
13. 把状态挂到 msg.id 上：重载后 id 从 l1 变成 h9512，旧数据全部失联

## 11.1 执行时机

- **脚本先于 DOM**：作者脚本在平台挂载功能栏与消息 HTML 之前就执行完毕。顶层直接 document.getElementById 恒为 null；任何 DOM 读写都必须放进事件回调。
- **回调参数**：1 个（SDK 回调只传 1 个实参（payload）。官方契约写的第二参 bubbleRoot 不是 SDK 提供的，不要依赖。）
- **消息 id**：msg.id 是本地自增或 h+serverId 派生，跨重载会变（l1 → h9512）；持久化与定位一律用 msg.serverId（等于 data-msg-id）。开场白 id 为 'greeting'、serverId 为 null、data-msg-id 为 -1。
- **serverId 判空**：serverId === null 表示服务端还不认得这条，不可 message.edit；调用前必须判空。

## 11.3 句式禁令（人设 / 世界书 / 开场白）

| 项 | 规则 | 改法 |
|---|---|---|
| 先否定再肯定 | 禁止「不是…是…」「不是…而是…」「与其说…不如说…」这类句式 | 删掉否定那半句；删完不通就把后半句补成完整陈述，仍不写成对偶 |
| 生硬比喻 | 禁止「A等于B」「A就是B」式判断句冒充比喻 | 写 B 的具体特征，让读者自己得出 A 像 B；不要用系词直接等号 |
| 术语腔与抽象词堆叠 | 禁止外显、建制、成正比、位移、闭环、赋能、维度、底层逻辑这八个词，以及同类名词化抽象 | 换成可观察的动作、位置、数量、时间；写不出具体画面就删掉整句 |
| 同段重复 | 禁止同一句信息在两处原样重复；同一段里意思重复的句子只留一句 | 保留信息更具体的那句；另一句改成推进（代价、后果、例外），改不了就删 |

人设 / 世界书 / 开场白三处同受约束；说明性文档（本 skill 的方法论文档）不受约束。

## 11.4 AI 腔信号（全部 WARN）

人写稿实测：平均每行 30.7 字、行末无标点 84%、句号密度 12.7‰、长句 5.6%、排比 1、对偶 0、因果 0、破折号 1。AI 稿：44.6 字、32%、27.6‰、11.1%、3、1、2、5。

| 信号 | 判定 | 改法 |
|---|---|---|
| 平均每行过长 | 平均每行 >40 字 | 一行一件事，写完就停 |
| 长句过多 | 长句（>40 字）占比 >8% | 拆成两句，或改用分号 |
| 句号偏多 | 句号密度 >18‰ | 字段行不必加句号；笔记体不是文章 |
| 排比三连 | 「；…；…」三段并列 ≥3 处 | 保留两项，或拆成两句 |
| 对偶金句 | 「X很A，Y很B」≥1 处 | 拆开写，信息不变 |
| 因果解释 | 因为 / 所以 / 因此 / 从而 / 于是 ≥1 处 | 删连接词，两句并列 |
| 破折号过多 | —— ≥4 处 | 改用括号，或另起一句 |
| 每字段写满 | 一个字段 3 段以上且有起承转合 | 删一半，看角色会不会变 |

全部 WARN。阈值来自人写稿与 AI 稿的量化差（references/32 §0），题材不同会合理偏离，只提示不拦截。
