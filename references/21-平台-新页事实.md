# 21 · 新版沙盒

适用 chatVersion=1。机器名单/限额见23，SDK签名见25。历史探针是有目标和日期的证据，不自动代表当前站点。

- 纯 style/script 装卡抽取，不要求正文标记命中；可见 HTML 仍需连到 statusbar、beginning、模型标记或前序替换。
- 脚本可能早于 Vue 挂载内容；在生命周期里查询需要的节点，顶层主要定义/订阅。不要把“任何时刻都查不到DOM”推广成通用事实。
- 气泡绑定用 message:mount，正文从 message:stream/done 的 msg.content 取。回调只依赖已记录契约，不假定第二个 bubbleRoot 参数。
- 长期画布/面板用舞台；气泡卸载时清理局部监听，切会话重读进度，dispose 销毁运行时。
- 模型状态统一 [status] JSON [/status]，与 status.js、build 隐藏规则及 preview 模型一致；不生成其他状态壳。只换肤不要求模型吐状态。
- 空 statusbar 合法；自写静态 data-* 会被净化，运行时自己的 DOM 与平台自带稳定属性另分。
- HTML 顶格是保守约定；已有源码样本会清行首空格，不把四空格当所有新版必然故障。反引号包住的 HTML 才会作为源码展示。
- 角色 CSS 不直接穿透跨源父层；公开主题桥与受控 data-host CSS 的条件能力见47。
- 29个主题变量与层级是已记录样本；作者浮层须按实际层叠上下文验收，不把固定安全数段套所有节点。
- sdk.save 用于需要跨刷新保留的进度，cache 仅当次页面。平台变量契约未齐，不写推测签名、字段或隐藏 abc_vars 的正则。

导入、编辑器和公开审核分别建预算；保守 replaceString≤20000，源码导入路径样本100000并非建议绕编辑器。scriptName/findRegex 的双路径仍待确认。save.remove 的历史 NETWORK 故障应按目标复验，不能说所有部署永久坏死。
