# 43 · 封面与捏人（参考实现）

> 本文恢复旧版参考卡封面/捏人的结构与公式，是设计资料，不是当前默认骨架全部已实现的功能。新版把场景接到sdk.stage；旧版同层在Frame内实现；旧版原生可用自建层。
> 比例、步数、三区宽度都是那张卡的参数；换画布、换核心循环时要按 §1.2 的公式重算，不要照抄像素。
> 术语见 [45 工程骨架与创作皮肉](45-界面-骨架与皮肉.md)：**结构属于工程骨架，视觉属于皮肉，下限是另一层。**

## 1. 封面

### 1.1 DOM 结构（工程骨架）

```
section.open-cover[aria-label="开局"]         ← 整屏可点
├─ img.cover__art                              ← 底图（fetchpriority=high）
├─ div.cover__layers                           ← 分层容器（视差/景深）
│   └─ 多层 img.cover__layer                   ← 绝对定位，各自 transform
├─ div.cover__composition                      ← 世界坐标画布，居中缩放
│   └─ button.cover__start                     ← 入口，按百分比定位
│       ├─ span.cover__accessible              ← 视觉隐藏文本「进入」
│       └─ img.cover__lettering                ← 标题图（可选，也可用排版）
├─ button.cover__motion                        ← 动效开关
├─ .cover__notice                              ← 提示（可选）
└─ .cover__passage                             ← 副文案（可选）
```

结构要点（与视觉无关）：

- 整屏可点 + 入口按钮 `stopPropagation`，两条路径都进得去；
- 入口必须有可读名称（视觉隐藏文本或可见文字）；
- 动效开关有 `aria-pressed`，键盘可聚焦；
- 画布容器负责缩放，内部元素用百分比定位，不写死像素。

### 1.2 尺寸：公式优先，示例值仅对照

| 元素 | 公式 | 示例值（1536×1024 画布） |
|---|---|---|
| 世界画布 | 任选基准，建议 3:2 | `1536 × 1024` |
| 构图容器 | `width: max(100cqw, (W/H)×100cqh)`<br>`height: max(100cqh, (H/W)×100cqw)` | `max(100cqw,150cqh)` / `max(100cqh,66.67cqw)` |
| 入口按钮 | 画布内百分比定位 + 最小点击区兜底 | `left 50.33% / top 44.97% / 7% × 24%`，最小 `60×130` |
| 标题图 | 按钮内百分比，`object-fit: contain` | `74.4% × 84.2%` |

**最小点击区不得小于 44×44 CSS px**（触控可达性），示例的 `60×130` 是因为它是一张竖排字图，不是通用要求。

这套数字的意义只有一个：**入口压在画面的视觉重心上，并且随画布缩放不跑位**。换了构图（左下角入口、无主视觉的纯排版封面）同样成立。

### 1.3 状态机（工程骨架）

```
loading → is-ready（分层淡入）
点击   → is-leaving（按钮 disabled）→ 进入捏人
动效关 → is-still
系统减少动效 → is-reduced（动画/过渡全部禁用）
```

状态名可以改，四件事不能少：**就绪、离场、手动关动效、跟随系统减少动效**。

### 1.4 交互与可访问性（工程骨架）

- 整屏可点；入口按钮阻止冒泡，避免重复触发。
- `aria-label` 说清"进入什么"；视觉隐藏文本兜底。
- 动效开关支持键盘与 `:focus-visible`。
- `prefers-reduced-motion` 下不播视差，直接显示静态构图。

### 1.5 复现项（仅复刻模式）

- [ ] 单层全屏，无平台 UI 干扰 ← **呈现形态，非骨架**
- [ ] 底图 + 分层容器（≥3 层）← **视觉手法，非骨架**
- [ ] 世界坐标画布 + 居中缩放
- [ ] 入口按百分比定位，最小点击区兜底
- [ ] 视觉隐藏文本 + `aria-label`
- [ ] 动效开关 + `prefers-reduced-motion`
- [ ] 四态：就绪 / 离场 / 静止 / 减少动效
- [ ] 整屏可点 + 按钮阻止冒泡

原创卡选择适合自己的交互；无需整屏可点或多态动画，但入口可达、键盘可用、有失败回退。

## 2. 封面 · 皮肉

| 项 | 示例做法 | 替换方向 |
|---|---|---|
| 主视觉 | 水墨长卷：分层山峦/雾气/人物 | 换题材主视觉，保留"分层景深"方法 |
| 标题 | 书法字图（不是字体排版） | 自写/自画一套字，或改成图形标志 |

## 3. 捏人

### 3.1 步骤模板（不是固定七步）

示例卡用了七步，但**步数与内容是结果，不是规则**。按 [44 捏人协议](44-界面-捏人协议.md) §2 从核心循环推维度，再决定怎么分步。

| # | 这一步收什么 | 示例 id | 必选 |
|---|---|---|---|
| 1 | 姓名 / 年龄 / 性别 | `person` | ✅ |
| 2 | 力量体系 / 等级 | `realm` | ✅ |
| 3 | 社会身份 / 来历 | `identity` | ✅ |
| 4 | 可选标签（多选） | `traits` | ⬜ |
| 5 | 初始物品 | `items` | ⬜ |
| 6 | 开局事件 / 处境 | `events` | ⬜ |
| 7 | 起始地点 | `location` | ✅ |

分步规则（可迁移）：

- **必选放两头，可选放中间**：用户不会在第三步就烦。
- **3–7步**可作复杂创建起点；单步轻捏人与更长的编辑器也可成立，数量按需求和实际试用决定。
- **可合并**：身份与来历、行囊与特质都可以并；并完仍要保证每步有"选择即预览"。
- **步骤名、标题、引导语属于皮肉**：示例里的原句不抄，只保留结构与必选/可选标记。

### 3.2 布局：三区是一种，不是唯一

```
.creation
├─ .creation-landscape            ← 背景（静帧 + 分层 + 地点切换）
├─ .creation-scroll
│   ├─ .creation-topbar           ← 世界名 / 返回 / 动效 / 跳过
│   ├─ .creation-folio            ← grid: 章节栏 | 主区 | 摘要栏
│   │   ├─ .creation-chapters     ← 章节导航（编号/短名/进度）
│   │   ├─ .creation-main         ← 标题 + 引导 + 选项/表单
│   │   └─ .creation-summary      ← 实时摘要 + 已选清单 + 回看
│   └─ .creation-bottom           ← 已选计数 + 上一步/下一项
```

| 区 | 示例宽度 | 职责 | 可替换为 |
|---|---|---|---|
| 章节栏 | 84px | 步骤导航，`aria-current="step"` | 顶部进度条 / 分步圆点 |
| 主区 | 自适应 | 当前步骤的选项/表单 | 不变 |
| 摘要栏 | 248px | 名字/身份/已选项 | 底部抽屉 / 折叠面板 |

**窄屏**：章节栏横排、摘要折叠到下方、主区单列——这条是下限，不是选择。

### 3.3 主区的四种形态（按选项规模选）

| 形态 | 用于 | 关键点 |
|---|---|---|
| 选项网格 | 3–12 项 | 选中态有明确勾选块，整行可点 |
| 搜索 + 网格 | 选项 > 12 | 搜索框在左上，不占满行 |
| 表单 | 姓名/年龄等自由输入 | 标签常显，不用 placeholder 当标签 |
| 自定义 | 预设不够 | 展开 `textarea`，有字数提示 |

### 3.4 校验（规则随字段走）

| 字段 | 规则 | 错误提示位置 |
|---|---|---|
| 姓名 | 去空格后非空 | 字段下方 |
| 年龄 | 正整数（按题材可改为年龄段） | 字段下方 |
| 性别/称谓 | 必选其一（选项按题材定） | 选项组下方 |
| 地点 | 必须在列表内 | 由选项本身保证 |

**时机**：点「下一项 / 开始」时校验当前步；错误就地显示，不弹窗。

### 3.5 摘要与回看（体验下限）

- 摘要实时更新；空值显示可读占位（如"待填写"），不显示空白。
- 每个区块可点击跳回对应步骤。
- 「回看」打开完整摘要，确认后开始。

### 3.6 复现项与下限项

**复现项（仅复刻）**

- [ ] 步骤顺序与必选/可选标记
- [ ] 三区结构与宽度比例
- [ ] 章节栏 `aria-current=step` + 编号 + 短名
- [ ] 主区四种形态（网格/搜索/表单/自定义）
- [ ] 实时摘要 + 点击回跳
- [ ] 校验时机与错误位置
- [ ] 底部计数 + 上一步/下一项
- [ ] 键盘可达、焦点可见
- [ ] 窄屏：章节栏横排、摘要折叠、主区单列

**选用了创建流程后的检查项**

- [ ] 每步有标题 + 一句引导
- [ ] 选择后能看到后果
- [ ] 必填未完成时不能进入下一步
- [ ] 可返回上一步修改
- [ ] 窄屏不横向滚动
- [ ] 键盘能走完全流程

## 4. 捏人 · 皮肉

| 项 | 示例做法 | 替换方向 |
|---|---|---|
| 底色 | 纸白 `#efe6d3` / 墨绿 | 换一套底色 |
| 强调 | 朱砂 `#913c2c` + 印章 | 换强调色与"印记"语言 |
| 字体 | 文楷标题 + 宋体正文 | 换字族（科幻用无衬线/等宽） |

| 摘要栏 | 书页边栏、竖排小字 | 换成数据卡/终端侧栏 |

若目标是原创视觉，应重新设计题材语言；若用户有权复用并明确要求保留，则按该范围执行。

## 5. 施工顺序

```
1. 先定工程骨架：封面的四态、入口、返回；捏人的步骤、校验、摘要回跳（用色块与假数据）
2. 跑通一次完整流程（封面 → 捏人 → 主界面），确认没有断头路
3. 再换皮肉：tokens → 主视觉 → 字体 → 动效
4. 灰模对比看结构，彩模对比看气质
```

**不要先做美术**。工程骨架没定，画面再精细也要重排。

## 6. 边界

- 原卡素材、字图和文案的复用按实际授权处理；未经授权的参考只学方法，不自动搬运。
- 可以学：分层景深、中心入口、三区布局、分步顺序、校验时机、摘要回跳。
- 判断标准：**两张封面去色后结构可以像，加回颜色应该一眼看出是两张卡。**


## 7. 当前骨架的具体边界与回归

features.cover/forge四种组合的启动表见40；有有效自动档则恢复主界面。默认是一个可滚动的字段列表，不含本篇示例的七步导航、搜索、摘要回跳、整屏点击和视差。需要这些功能时逐项实现与验收，不能因本篇写过就列为已支持。

当前字段支持text/choice，choice可从map.nodes读取；optional:true可空，必填text去空白后非空，maxLength（兼容text.max）限制长度，choice值必须属于配置列表。按钮状态与commitForge走同一校验，直接调用也不能绕过。年龄、数值范围、禁用组合等额外规则由项目扩展。

- [ ] cover/forge四种组合均可启动，没有关掉捏人仍跳进forge
- [ ] 必填文本为空/仅空白、选择缺失、非法选择和超长文本都被拒绝
- [ ] 可选空值可提交，默认值显示与实际提交一致
- [ ] 返回修改不丢选择；无封面时返回主界面，不强行打开cover
- [ ] 点“入局”只填草稿，输入失败留在创建页并提示，不假称已完成
- [ ] 项目自定义维度与状态初值真实关联；默认不推导任意字段后果
