# 22 · 同层卡架构（两个范式）

> 适用于旧页；独立正则包不带 chatVersion。新版沙盒走 SDK，不套本文。
> 以下两个历史范式来自成品卡拆解，不等于自带基座的全部实现：**A = HUD 接管**（100 条规则 / 1.87MB），**B = 原生增强**（68 条规则 / 633KB）。

---

## 1. 范式 A · HUD 接管型

### 1.1 三层结构

```
平台页面（原生聊天）
├─ Host 脚本（注入到平台页，能摸原生 DOM）
│   ├─ 选择器适配层（146 个选择器 → 消息/输入/指令/设置/总结/更多）
│   ├─ 动作分发器（历史参考含61项；本基座见下方能力表）
│   └─ 创建 <iframe> + MessagePort
└─ Frame（隔离 iframe，自带完整 UI）
    ├─ 自己的状态机 / 渲染 / 路由
    ├─ 定向握手后通过 MessagePort 请求宿主做事
    └─ 不直接碰平台 DOM（跨源也碰不到）
```

**为什么这么分**：Frame 是普通网页，可以随便写框架、CSS、动效；Host 只做"翻译"，把 Frame 的请求翻译成原生点击。平台改版时只改 Host。

### 1.2 注入链（旧版没有 SDK，只能靠正则链）

```
statusbar: 【RexHUD 001】
  │ 规则 001 → 塞入 h 分片 1 + 标记 002
  │ 规则 002 → 塞入 h 分片 2 + 标记 003
  │ …
  │ 规则 009 → 塞入 f 分片 1 + 标记 010
  │ …
  │ 规则 100 → launcher：读累积串 → 建 <script> → 执行 Host
  ▼
Host 建 iframe → Frame boot → frame-ready → 开始工作
```

- `h` = Host 源码，`f` = Frame 源码，两段分开累积。
- 每条规则只做一件事：`s.h = (s.h ?? '') + "<本片>"`，尾部接下一个标记。
- launcher 必须校验两段都非空，缺一段就抛错（宁可见错，不要半启动）。

> **⚠️ 链式只是其中一种拓扑。** 平台也可能"每条规则各自作用在原文"——这时链式只有第 1 条命中，**零报错、零渲染**。
> 默认应改用**独立点火**：把全部标记一次性写进 `beginning`，每条规则只认自己那一个；它在两种语义下都能全量点火。
> 详见 [53-验收-真平台踩坑](53-验收-真平台踩坑.md) §1。`pack-samelayer.mjs` 默认就是 `--ignite independent`。

### 1.3 分片数学与真实实现

当前 pack-samelayer 按**原串逐字符计算转义后的预算**切片，再对每片转义；不是先切转义串再只数反斜杠。这样不会切断 Unicode 转义或代理对。

| 项 | 当前口径 |
|---|---|
| 替换硬预算 | 每条最终 wrapper+载荷+尾标记不超过20000字符 |
| 默认载荷预算 | 转义后19000，--limit 可设32–19000 |
| 片数 | Host与Frame分别按转义成本累计，不能用原字节数直接除 |
| 规则数 | Host片+Frame片+launcher；init已携带第一份Host片，不另加空init |
| 起点 | 默认 independent，把所有标记一次写进beginning；其总长也需≤4000 |

转义包括反斜杠、双引号、换行/回车/制表符、<、$、U+2028/U+2029。其中<写成\u003c避免提前闭合script，$写成\x24避免捕获组与状态替换。不要手工拼片。构建后还原载荷、比对源码并检查脚本语法；manifest只是本地打包证据。



### 1.4 Host 适配层怎么写

把消息、输入、发送、人设、更多面板等选择器集中管理，REXHUDCONFIG.selectors可按目标覆盖。候选来自实际页面，缺少第二个可靠候选就只用一个，不用新版data-chat伪装旧版兼容。

1. 找不到元素时返回{ok:false,reason:'not-found'}等可读结果，Frame提示当前不可用。
2. 输入与发送区分；已有不同草稿先保护，不无条件覆盖。
3. 打开原生弹层时同层让位，保留“返回同层”入口，避免弹层被Frame盖住。
4. 动作按副作用设计忙锁、去重与结果确认，不把固定200ms节流当通用正确性保证。



### 1.5 历史参考动作（61项的分组，不是当前实现表）

| 组 | 高频动作 | 备注 |
|---|---|---|
| 消息 | `openEditMessage` `setEditText` `submitEditMessage` `deleteMessage` `rollbackMessage` `startNewStoryFromMessage` | 删除要带确认令牌；回溯会新建分支 |
| 会话 | `openConversationPanel` `selectConversation` `renameConversation` `deleteConversation` `createConversation` `refreshConversation` | 切换后要清缓存、重读存档 |
| 人设 | `openPersona` `setPersonaName` `setPersonaGender` `setPersonaIdentity` `submitPersona` | 写入是异步的，提交后要回读确认 |
| 补充设定 | `openSupplement` `setSupplementText` `submitSupplement` | 同上 |
| 指令 | `openPromptSelector` `applyInstruction` | 只填充，不自动发送 |
| 设置 | `openChatSettings` `submitChatSettings` `setModelSetting` | 平台弹窗，只能操作不能重画 |
| 更多/分享 | `openMoreMenu` `activateMoreMenuItem` `openSharePanel` `toggleFavorite` `openComments` `exit` | `activateMoreMenuItem` 只认少数 kind，别假装全能 |

**四条硬规则**：

1. **没实现的功能不做假入口**。关闭入口或返回原生；不能用卡内仿制设置页冒充真实账号/模型设置。
2. 能力先探测，明确区分未找到、未实现、权限不足；读不到不能直接推断用户无权限。
3. 选项默认只写草稿。明确启用发送功能后由玩家确认，发送锁保护，失败可见。
4. **失败要可见**。16s 超时抛"结果未确认"，不要静默当成功。

### 1.6 当前基座、通信与存储

Host 负责旧版 DOM、动作、能力和有作用域的本地存储；Frame 是 sandbox=allow-scripts 的隔离 srcdoc UI，不读父 DOM 或父存储。首次定向握手传 MessagePort，后续请求带会话随机标识与请求 id；不接收其他 Frame 的任意动作。

自带最小基座实现 snapshot、setInput、send、openPersona、openMore、fillDialog、confirmDialog、capabilities、storage.get/set、returnNative。编辑/删除/回溯返回 not-implemented；参考上游61项不是本基座实现数量。当前可用性还受 DOM、授权配置和状态影响，真站均需项目验收。

发送保护不同的原生草稿，结果区分已触发、回复完成和服务端保存；不自动重试。确认原生提交要求 confirmed。打开原生面板时同层让位，返回同层按钮保留；离开路由销毁 port、节点和监听，重入不叠实例。

本地存档仅在 Host 获得经过验证的 REXHUDSCOPE() 或配置 scope 时启用，三项 accountKey/roleId/conversationKey 必须齐全。无 scope 明确不可用，不用姓名、DOM序号或固定 main 猜作用域。它不是跨设备 SDK 存档。

pack-samelayer 将 Host/Frame 安全转义分片，默认独立标记一次放进 beginning；每条旧版 id=-1、顶层四键。分片完整性、真正 String.replace 语义、载荷还原和脚本语法都要测。launcher 缺任一载荷失败，manifest 只标达到的证据。

按作品扩展选择器与动作，不要求虚构两个候选凑数，不使用新版稳定钩子伪装旧版兼容。能力表列参考/已实现/当前可用/实测；没有动作时关闭入口或保留返回原生。旧版原生换肤与轻量同层可组合。


扩展动作时依次完成：Host处理器→允许动作/能力投影→Frame入口与降级→本地真实事件链→目标站可见效果。消息体结构以host.js与frame.html为准，不用历史通用invoke示例覆盖当前type/method/session协议。请求有超时；超时标“结果未确认”，删除/提交/发送不自动重试。



## 2. 范式 B · 原生增强型

### 2.1 结构

```
beginning: 【rex-mod-a】【rex-mod-b】【rex-mod-c】…（标记串，一次性点火）
  │ 每条规则 findRegex = /【rex-mod-x】/ → 替换成 <style> 或 <script>
  ▼
window.__XXX_MOUNT__（单例运行时）
  ├─ register('screens', fn)   // 封面 / 标题 / 转场
  ├─ register('forge', fn)     // 捏人
  ├─ register('wiki', fn)      // 百科
  ├─ register('status-data', fn)// 状态渲染
  └─ register('repair', fn)    // 状态栏自诊断
```

- 不建 iframe，直接把自建层插到原生页上。
- 原生增强默认可只换肤和加场景；需要动作时可组合轻量Host，经适配后逐项验收。
- 适合"想保留原生聊天手感"的卡。

### 2.2 运行时三条

```js
var OWNER='__XXX_MOUNT__', VERSION=128;
var prev = window[OWNER];
if (prev && prev.version >= VERSION) { prev.reenter(); return; }  // 重入
if (prev && prev.destroy) prev.destroy();                          // 旧实例清理
```

1. **单例 + 版本守卫**：重复装卡/预览重跑不叠层。
2. **`register` 幂等**：同名模块第二次注册直接返回。
3. **`destroy` 要真清**：计时器、监听、observer、注入的节点全要清，否则切会话后幽灵响应。

### 2.3 模块怎么分

一份成品卡的分布（68 条）：CSS 26 / JS 38 / 其它 4。按职责分：

| 类 | 典型模块 |
|---|---|
| 换肤 | 原生聊天页、弹窗与设置、对话框与控件 |
| 场景 | 挂载层、标题与字幕、捏人、角色库、百科、音乐 |
| 状态 | 状态数据、渲染、消息尾栏、阅读导航 |
| 体验 | 气泡设置、开场动画、底纹、诗篇 |
| 自诊断 | 状态冲突分析、版本选择、修复交互 |

**自诊断是加分项，不是必需**。它的价值：玩家状态栏格式崩了，界面能告诉他"你这份是旧协议，点这里按新版重解析"，而不是白屏。

## 3. 选型

| 需求 | 选 A（HUD 接管） | 选 B（原生增强） |
|---|---|---|
| 需要原生动作 | Host逐项实现，不因选A就自动支持 | 可叠轻量Host；纯CSS本身不提供动作 |
| 要完全自定义信息架构 | ✅ | 部分 |
| 想保留原生聊天手感 | 设计让位与返回 | 适合 |
| 体积敏感 | 最小Frame也可很小，完整应用才可能很大 | 可从少量规则起步 |
| 团队只一个人、要快速出 | ❌ 两套代码 | ✅ 一套 CSS + 几个模块 |
| 平台改版风险 | 高（146 个选择器） | 中（主要是 class） |

**混合也可以**：B 的换肤 + 一个轻量 A 的浮动面板（只做 3~5 个动作）。但不要两边都做全套，维护不起。

## 4. 共同不变量（两个范式都必须满足）

1. **单例**：`window.__X__` 唯一，带版本守卫。
2. **幂等**：重复点火不叠界面、不重复订阅。
3. **标记必须被消耗**：链尾不得残留 `【…】` 或 `<tag>`。新写的卡统一用 `【rex-xxx】`，不用尖括号。
4. **首屏不空**：找不到宿主时显示"未连接/加载失败"，不要白屏。
5. **失败可见**：任何异步动作有超时与错误提示。
6. **不自动发送**：写输入框，不替玩家按发送。
7. **状态可缺**：解析失败保留上一次数据，不清零。
8. **双端**：PC 三栏 / 手机单列，断点实测不估算。
9. **不抢焦点**：输入中不重绘输入框。
10. **退出可回**：每层都有返回；ESC 能关浮层。
11. **体积可控**：分片前先算总字节，别等打包才发现超 130 条。
12. **证据分级**：本地跑通 ≠ 真机可用。

## 5. 反模式

| 反模式 | 后果 |
|---|---|
| 运行时 `eval` 拼接整个应用 | CSP/净化器拦，失败留半截状态 |
| 把 Frame 代码塞进 `statusbar` | 200 字上限，必然超限 |
| 所有动作写在一个 3000 行函数里 | 改一个动作要重读全部 |
| 用 `innerHTML` 拼用户内容 | XSS + 净化器改写 |
| 依赖单一 class 选择器 | 平台改版即全废 |
| launcher 不校验载荷 | 半启动，界面花屏 |
| 分片切在转义序列中间 | 整条静默丢弃 |
| 认为 `$` 是普通字符 | 被当捕获组，内容丢失 |
