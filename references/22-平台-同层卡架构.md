# 22 · 旧版同层

Host 负责旧版 DOM、动作、能力和有作用域的本地存储；Frame 是 sandbox=allow-scripts 的隔离 srcdoc UI，不读父 DOM 或父存储。首次定向握手传 MessagePort，后续请求带会话随机标识与请求 id；不接收其他 Frame 的任意动作。

自带最小基座实现 snapshot、setInput、send、openPersona、openMore、fillDialog、confirmDialog、capabilities、storage.get/set、returnNative。编辑/删除/回溯返回 not-implemented；参考上游61项不是本基座实现数量。当前可用性还受 DOM、授权配置和状态影响，真站均需项目验收。

发送保护不同的原生草稿，结果区分已触发、回复完成和服务端保存；不自动重试。确认原生提交要求 confirmed。打开原生面板时同层让位，返回同层按钮保留；离开路由销毁 port、节点和监听，重入不叠实例。

本地存档仅在 Host 获得经过验证的 REXHUDSCOPE() 或配置 scope 时启用，三项 accountKey/roleId/conversationKey 必须齐全。无 scope 明确不可用，不用姓名、DOM序号或固定 main 猜作用域。它不是跨设备 SDK 存档。

pack-samelayer 将 Host/Frame 安全转义分片，默认独立标记一次放进 beginning；每条旧版 id=-1、顶层四键。分片完整性、真正 String.replace 语义、载荷还原和脚本语法都要测。launcher 缺任一载荷失败，manifest 只标达到的证据。

按作品扩展选择器与动作，不要求虚构两个候选凑数，不使用新版稳定钩子伪装旧版兼容。能力表列参考/已实现/当前可用/实测；没有动作时关闭入口或保留返回原生。旧版原生换肤与轻量同层可组合。
