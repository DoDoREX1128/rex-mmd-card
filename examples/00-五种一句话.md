# 00 · 五种一句话，各自推出什么

五句真实长度的输入（都在 20 字以内），按 [11-流程-一句话补全](../references/11-流程-一句话补全.md) 的协议推演。
**看的是推演过程，不是成品。** 同一套骨架，五个完全不同的卡。

---

## ① 「暴雨夜的旧书店，老板记得每个借书不还的人」

| 维度 | 推出 | 依据 |
|---|---|---|
| 信号 | 时代=当代 / 场景=旧书店 / 关系=债主与欠债人 / 压力=人情债 / 欲望=被记住 |
| 重心 | 关系为主，解谜为辅 | 「记得」= 有旧账，一定有故事 |
| 主题 | 雾蓝 `#7fb2c9` + 浅陶 `#e8a798`，**浅色底** | 日常题材不该用暗底 |
| 专属资源 | **不加** | 没有硬资源压力，加了就是画蛇添足 |
| 状态 | 六字段，`hp` 的 label 改成「精神」 | 熬夜伤的是精神不是血 |
| NPC | 主：老板 · 镜：常来的读者 · 刺：唯一没还书的那个人 | 「没还书的人」就是压力源 |
| 开场 | 雨打铁皮棚 → 门铃没响 → 柜台上的借书卡翻到某一页 | 钩子=那一页写着谁 |
| 我定的 | 老板为女性；这本书是玩家自己借的 | 写进 `assumed` |

**这张教的是克制**：不是每张卡都要专属资源、都要 5 个 NPC。**该少的少，才是为题材做的。**

## ② 「民国上海，她在雨里等一个不会来的人」

| 维度 | 推出 | 依据 |
|---|---|---|
| 信号 | 时代=民国 / 场景=街头 / 关系=旧情 / 压力=等待 / 欲望=被需要 |
| 重心 | **关系为主**（80%），解谜为辅 | 全句都在讲一段关系 |
| 主题 | 桐油 `#a67c52` + 深墨绿 `#2d4a3e`，胶片质感 | 民国表 |
| 专属资源 | `silver` 银钱 + `clue` 线索 | 「不会来」= 有个原因 → 需要查 |
| 状态 | 砍 `hp`，留 `desire/intimacy/loc/t/clue/silver` | 没有战斗，`hp` 是死字段 |
| NPC | 主：等的那个人（不在场，靠信与传闻存在）· 镜：闺蜜 · 刺：未婚夫 | 「不在场的主 NPC」是这类卡的杀手锏 |
| 开局 | 伞沿的水线 → 街对面没有脚步声 → 手里那封信被雨洇开一个字 | 钩子是「那个字是什么」 |
| 我定的 | 主 NPC 全程不正面出场，只通过信、传闻、他人之口存在 | 这是最大胆的一处，必须写进交付说明 |

**关键判断**：原句没提「打斗」，所以 `hp` 该砍。**敢砍字段，卡才像为这个题材做的。**

## ③ 「星舰坟场，捡垃圾的少女和一台还在运行的 AI」

| 维度 | 推出 | 依据 |
|---|---|---|
| 信号 | 时代=远未来 / 场景=坟场 / 关系=人机 / 压力=资源 / 欲望=理解 |
| 重心 | 探索 + 关系 | 「捡垃圾」= 探索，「还在运行」= 悬念 |
| 主题 | 青 `#00d9c0` + 品红 `#ff2e63`，霓虹 | 赛博表 |
| 专属资源 | `fuel` 燃料（比银钱更贴） | 坟场里最缺的是能跑起来的东西 |
| 状态 | `hp / fuel / desire / intimacy / loc / t / flags` | 7 个 |
| NPC | 主：AI（无身体，活在终端里）· 镜：另一个拾荒者 · 刺：回收公司的清道夫 | AI 的 `priv` 怎么办？——**见下** |
| 特殊 | AI 没有身体 → `priv` 全空，里层显示「这一层还没被写开」 | 允许空，不要硬编 |

**这张卡教的是边界**：骨架默认每个 NPC 都有 3~5 个部位。**遇到无身体的角色，就让它空着**，界面会显示占位文案，不崩、不假。硬编一套部位才是毁卡。

## ④ 「女儿国的守门人，三百年没见过男人」

| 维度 | 推出 | 依据 |
|---|---|---|
| 信号 | 时代=架空古国 / 场景=城门 / 关系=陌生人 / 压力=禁忌 / 欲望=好奇 |
| 重心 | 关系 + 世界 | 「三百年没见过」是世界观钩子 |
| 主题 | 暗朱 `#7a1f1f` 为主色（不是陈金） | 「女儿国」偏禁忌与血，不用金石气 |
| 专属资源 | `qi` 灵气（若设定有）或直接砍掉，只留 6 字段 | 原句没有资源压力 → 别硬加 |
| NPC | 主：守门人 · 镜：国中长者 · 刺：执律者 | 「禁忌」需要一个执行禁忌的人 |
| 关系初值 | `desire` 高（≥40），`intimacy` 为 0 | 这是这张卡的发动机，初值必须体现 |
| 我定的 | 玩家默认为男性；守门人为女性 | 原句隐含，但必须在 `assumed` 里写明 |

**这张教的是初值**：`desire` 初值 40 和初值 0 是两张完全不同的卡。**开局的数值就是开局的语气。**

## ⑤ 「深夜便利店，值夜班的她，和每天凌晨三点来的那个人」

| 维度 | 推出 | 依据 |
|---|---|---|
| 信号 | 时代=当代 / 场景=便利店 / 关系=熟客 / 压力=重复 / 欲望=被看见 |
| 重心 | 关系（近乎 100%） | 没有任何外部压力源 |
| 主题 | 雾蓝 `#7fb2c9` + 浅陶 `#e8a798`，**浅色底** | 校园/日常表是全套里唯一的亮底 |
| 专属资源 | **不加** | 6 字段足够；加了就是画蛇添足 |
| 状态 | `hp` 改名为「精神」，因为夜班掉的是精神不是血 | **字段可以改名**，键名不动 |
| NPC | 主：她 · 镜：白班同事 · 刺：**没有** | 这类卡不需要反派，压力来自「他今天还来不来」 |
| 地图 | 只有 4 个节点：店里 / 后巷 / 仓库 / 公交站 | **小地图是对的**，别为了好看编八个地点 |
| 开局 | 关东煮的热气 → 门上的风铃没响 → 挂钟指向 2:58 | 钩子=「三分钟后」 |

**这张教的是地图密度**：4 个节点写得透，胜过 10 个节点写得空。地图节点数 = 剧情的真实密度。

---

## 从五张里能读出什么

1. **字段要敢砍。** 没有战斗就砍 `hp`，没有资源就不加专属资源。
2. **字段可以改名。** 键名固定（解析靠它），`label` 随便改（玩家看的是它）。
3. **NPC 可以缺席、可以没有身体、可以没有反派。** 空着比硬编好。
4. **初值就是语气。** `desire` 40 和 0 是两张卡。
5. **地图节点数 = 剧情的真实密度。** 4 个节点写得透，胜过 10 个节点写得空。
6. **每张卡都有 1 个「最大胆的推断」**，它决定这张卡像不像人做的 —— 也必须在 `assumed` 里交代清楚。
